# Learn Taipa from a client component to server HTML.

Start with one small component mounted in the browser. Then take the same definition to the
server, keep its HTML, and attach behavior without a virtual DOM.

## Pick a path

| Path                                  | What you build                                 | Best for                                               |
| ------------------------------------- | ---------------------------------------------- | ------------------------------------------------------ |
| [Basic](/basic/client-component/)     | A browser-mounted counter                      | Learning the component model in a few minutes          |
| [Advanced](/advanced/server-islands/) | The same counter as server HTML plus hydration | Integrating with a server-rendered application         |
| [Forms](/forms/)                      | A validated native signup form                 | Adding progressive enhancement without losing fallback |
